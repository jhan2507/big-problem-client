DevOps Scripts cho Client (big-problem-client)

- Dựng: Windows `scripts\devops\up.bat`, macOS/Linux `scripts/devops/up.sh`
- Dừng: Windows `scripts\devops\down.bat`, macOS/Linux `scripts/devops/down.sh`
- Rebuild: Windows `scripts\devops\rebuild.bat`, macOS/Linux `scripts/devops/rebuild.sh`

Mặc định `NEXT_PUBLIC_API_BASE_URL=http://localhost:8080`. Gán biến môi trường nếu cần.
